# CMF / Nothing Watch Cryptography Reference

## 1. Cryptographic Primitives

- **Cipher**: AES-128 in Cipher Block Chaining (CBC) mode with PKCS7 padding.
- **Fixed IV**:
  ```text
  hex: 50 51 52 53 54 55 56 57 60 61 62 63 64 65 66 5A
  bytes: [0x50, 0x51, 0x52, 0x53, 0x54, 0x55, 0x56, 0x57, 0x60, 0x61, 0x62, 0x63, 0x64, 0x65, 0x66, 0x5a]
  ```
- **Checksum**: Standard IEEE 802.3 CRC-32 (`0xEDB88320`), appended as 4 Little-Endian bytes.
- **Hash Function**: Standard SHA-256 for key derivation and challenge signatures.

---

## 2. Key Derivation Formulas

### 2.1 Long-term Pairing Key (`authkey` / K1)
Derived during initial pairing over the shell AT channel:
```python
authkey = SHA256(rnd1 || rnd2 || secret)[0..16]
```
- `rnd1`: 16 random bytes generated by the phone.
- `rnd2`: 16 random bytes generated by the watch.
- `secret`: 16-byte secret key returned by `AT GETSECRET`.

### 2.2 Per-Connection Session Key (`sessionKey`)
Derived on every connection during nonce exchange:
```python
sessionKey = SHA256(nonce || authkey)[0..16]
```
- `nonce`: Nonce bytes returned by `AUTH_NONCE_REPLY`.
- `authkey`: 16-byte persisted pairing key.

---

## 3. Frame Encryption & Decryption Flow

### 3.1 Encryption
```python
raw_body = payload_slice + CRC32_LE(payload_slice)
padded_body = pkcs7_pad(raw_body, block_size=16)
ciphertext = aes_128_cbc_encrypt(padded_body, key=session_key, iv=AES_IV)
```

### 3.2 Decryption & Validation
```python
padded_plaintext = aes_128_cbc_decrypt(ciphertext, key=session_key, iv=AES_IV)
raw_body = pkcs7_unpad(padded_plaintext)
payload = raw_body[:-4]
expected_crc = raw_body[-4:]
assert CRC32_LE(payload) == expected_crc
```
